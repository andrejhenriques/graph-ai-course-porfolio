About the course

8-week live cohort course

Generative AI for Work & Research

No-code AI tools for responsible task automation. Live weekly workshops, hands-on practice and personalized feedback from expert instructors, based at the University of Geneva.

  1. Module 1

    Websites, Documents & Presentations

    Learn about next token prediction and how large language models are trained. Write clear prompts to generate text for papers, grants and project websites, and design clear presentations using AI assistants.

  2. Module 2

    AI-Automated Data Analysis

    Use AI tools responsibly for analyzing quantitative data, from coding assistants to built-in data agents, and learn to spot hallucinations in statistical outputs.

  3. Module 3

    GenAI for Text Processing & Research

    Use LLMs in a loop to process hundreds of documents at once, extracting, classifying and summarizing information. Understand the limitations of LLM-powered text analysis and how to mitigate them.

  4. Module 4

    Custom GPTs and Chatbots

    Build chatbots with a custom knowledge base, instructions and tone. Learn how context windows and RAG shape what chatbots can do, and deploy external-facing chatbots safely.

  5. Module 5

    AI for Task Automation

    Discover how adding an LLM to traditional automations lets them handle nuance and unstructured data. Design workflows that run automatically when triggered.

  6. Module 6

    GenAI for Communication and Outreach

    Learn how image generation models work, and when to use HTML, SVG or pixel-based images. Design flyers, visual abstracts and scientific diagrams with AI.

  7. Module 7

    Capstone Project & Showcase

    Collaborate with peers and instructors to create and refine a final AI solution, tool or presentation, demonstrating responsible AI practice.

My weekly submissions

Each week follows the same rhythm: prework before the workshop, then a live workshop. My submission for each week will be linked below.

1 · Prework

About 4 hours of prework tasks per week, completed before the workshop.

Lessons Video tutorials and practice exercises.

Online quizzes Multiple choice theory quizzes.

2 · Workshop

Class time is used as a workshop where I apply the prework content and develop new skills while interacting with other students.

Whole-class teaching Instructors demo new concepts.

Group projects Practice skills with new datasets.
